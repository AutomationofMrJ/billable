# Working name review

Checked during the initial build on 3 October 2026. **Billable remains a provisional name.** An existing finance product uses the exact name at [billable.finance](https://billable.finance/), so it is a poor candidate for a distinctive public identity. This brief name check is not trademark clearance, a complete competitor survey or proof of domain availability.

The build keeps name and tagline in `shared/types.ts` (`BRAND`) so UI wording can change centrally. Storage paths, API headers and package identifiers are implementation identifiers; a final brand change should be coordinated so it does not strand existing workspaces or break the API contract.

| Alternative | Fit |
| --- | --- |
| **Workmoss** | Memorable, calm and compatible with the warm green visual direction; a tagline should explain its financial purpose. |
| **Earntrail** | Connects recorded work with the trail to invoices, payments and project contribution. |
| **Marginleaf** | Relates financial insight to the paper/green identity; explain “direct contribution” precisely, because it is before overhead and income tax. |

These are **unverified naming suggestions**. No claim is made about trademarks, company names, domains, app-store availability or legal availability. Prefer Workmoss as the distinctive creative direction for a later decision. Keep the current working name during the reliability build; name research must not delay the release flow.
